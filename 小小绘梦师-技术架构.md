### 1.2 技术选型

| 层级 | 技术栈 | 说明 |
|------|--------|------|
| **前端-H5** | React 18 + Vite + TypeScript | 高性能、良好的生态 |
| **前端-小程序** | Taro + React | 跨平台、一套代码多端运行 |
| **前端-后台** | Vue 3 + Element Plus | 企业级后台管理系统 |
| **网关层** | Kong / Nginx | API网关、负载均衡 |
| **后端框架** | Spring Cloud Alibaba | 微服务架构 |
| **后端语言** | Java 17 + Go | 业务服务用Java，AI服务用Go |
| **消息队列** | RocketMQ | 异步消息、解耦 |
| **缓存层** | Redis Cluster | 高性能缓存 |
| **数据库** | MySQL 8.0 | 关系型数据存储 |
| **文档数据库** | MongoDB | 非结构化内容存储 |
| **搜索引擎** | Elasticsearch | 全文搜索 |
| **对象存储** | MinIO / 阿里OSS | 文件存储 |
| **容器化** | Docker + Kubernetes | 容器编排 |
| **CI/CD** | GitLab CI + ArgoCD | 持续集成部署 |

### 4.2 故事生成服务

#### 4.2.1 服务流程

```python
# Story Generation Service

class StoryGenerationService:
    """故事生成服务"""
    
    def generate_story(
        self,
        child_age: int,
        theme: str,
        characters: List[str],
        length: str,
        style: str,
        user_id: str
    ) -> StoryResult:
        """
        生成故事
        
        Args:
            child_age: 孩子年龄
            theme: 故事主题
            characters: 角色列表
            length: 故事长度 (short/medium/long)
            style: 故事风格
            user_id: 用户ID
        
        Returns:
            StoryResult: 生成的故事结果
        """
        # 1. 构建提示词
        prompt = self._build_prompt(
            child_age=child_age,
            theme=theme,
            characters=characters,
            length=length,
            style=style
        )
        
        # 2. 调用LLM生成故事
        story_content = self._call_llm(prompt)

        # 4. 生成插图描述
        illustration_prompts = self._generate_illustration_prompts(processed_story)
        
        # 5. 保存记录
        story_id = self._save_story(user_id, processed_story)
        
        return StoryResult(
            story_id=story_id,
            content=processed_story,
            illustration_prompts=illustration_prompts
        )
    
    def _build_prompt(self, child_age, theme, characters, length, style) -> str:
        """构建生成故事的提示词"""
        age_description = self._get_age_description(child_age)
        length_words = self._get_length_words(length)
```

```python
        self.context_manager = ContextManager()
        self.safety_filter = SafetyFilter()
    
    async def chat(self, user_id: str, message: str) -> AgentResponse:
        """
        处理用户消息
        
        Args:
            user_id: 用户ID
            message: 用户消息
        
        Returns:
            AgentResponse: Agent响应
        """
        # 1. 获取用户上下文
        context = await self.context_manager.get_context(user_id)
        
        # 2. 情绪识别
        emotion = await self.emotion_classifier.classify(message)

            user_id=user_id,
            emotion=emotion,
            context=context
        )

            system=system_prompt,
            user=message
        )

            user_id=user_id,

            emotion=emotion,
```

```python
class EmotionClassifier:
    """情绪分类器"""
    
    EMOTIONS = {
        "happy": "开心",
        "excited": "兴奋",
        "calm": "平静",
        "sad": "难过",
        "scared": "害怕",
        "angry": "生气",
        "shy": "害羞",
        "curious": "好奇",
        "tired": "困倦",
        "hungry": "饥饿"
    }
    
    def __init__(self):
        self.model = load_emotion_model()
    
    async def classify(self, text: str) -> EmotionType:
        """
        识别文本中的情绪
        
        Args:
            text: 输入文本
        
        Returns:
            EmotionType: 识别的情绪类型
        """
        # 预处理
        cleaned_text = self._preprocess(text)
        
        # 情感分析
        emotion_scores = await self.model.predict(cleaned_text)
        
        # 获取最高情绪
        top_emotion = max(emotion_scores.items(), key=lambda x: x[1])
        
        return EmotionType(top_emotion[0])
    
    def _preprocess(self, text: str) -> str:
        """文本预处理"""
        # 移除特殊字符
        text = re.sub(r'[^\w\s]', '', text)
        # 标准化空白
        text = ' '.join(text.split())
        return text
```

## 8. 部署架构

### 8.1 容器化部署

```yaml
# docker-compose.yml
version: '3.8'

services:
  # API网关
  api-gateway:
    image: kong:3.4
    ports:
      - "8000:8000"
      - "8443:8443"
    environment:
      - KONG_DATABASE=postgres
      - KONG_PG_HOST=postgres
    depends_on:
      - postgres

  # 用户服务
  user-service:
    build: ./services/user-service
    ports:
      - "8081:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - NACOS_SERVER_ADDR=nacos:8848
    depends_on:
      - mysql
      - redis

  # AI服务
  ai-service:
    build: ./services/ai-service
    ports:
      - "8085:8080"
    environment:
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - VOLC_ACCESS_KEY=${VOLC_ACCESS_KEY}
    deploy:
      resources:
        limits:
          memory: 4G

  # MySQL数据库
  mysql:
    image: mysql:8.0
    environment:
      - MYSQL_ROOT_PASSWORD=${MYSQL_ROOT_PASSWORD}
      - MYSQL_DATABASE=xiaohui
    volumes:
      - mysql_data:/var/lib/mysql

  # Redis缓存
  redis:
    image: redis:7-alpine
    command: redis-server --appendonly yes
    volumes:
      - redis_data:/data

volumes:
  mysql_data:
  redis_data:
```
